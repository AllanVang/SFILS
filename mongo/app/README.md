To run the application you must do the following:

Note: Must have Python and Flask installed in order to run the application



Create a copy of the app.py file and templates folder (with the index.html within).
Access your systems terminal, navigate to the appropriate file path, and run 
app.py (in Powershell it would be: Python app.py).
Once it runs go to the link provided and you will have access to the database.
